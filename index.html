Your in-game sync code (NOT a real password) ▾ What's this?
Your Sync Code is a random string the bot gave you (like ABCD1234) so the app can find your stats.

It is NOT your Discord password, NOT your email, NOT anything sensitive. It only identifies your in-game account on this one game.

To find yours: type ?id in the game, or /sync-code in the Discord server.

The code is saved locally on your computer and is only sent to the Devast.io server (which already knows it).
